# @thomasfosterau/effect-biz

**Disclaimer:** This is an experiment. Don't use it in production.

The foundation of the effect-biz package family: the identifiers, tenancy context, error channel, domain events and repository conventions every effect-biz domain package builds on.

## Install

```sh
pnpm add effect @thomasfosterau/effect-biz
```

`effect` is a peer: your application owns the single copy.
