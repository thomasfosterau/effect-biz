Add the repository conventions (#28). `./Repository` defines `Port<A, I>` (`get`, `getMany`, `find`, `insert`, `update`, `archive`, `restore`, every method tenant-scoped and every write version-guarded) and `Deletable`; `./Audit` the `AuditFields` every stored entity carries (`createdAt`, `createdBy`, `updatedAt`, `updatedBy`, `version`, `archivedAt`), with `created`, `stamp` and `next`; `./Query` a typed filter and sort spec (`eq`, `in`, `range`, `search`, `archived`, `sort`) and its pure interpreter `run`; `./Page` keyset paging (`Page<A>`, opaque `Cursor`s, `limit` 50 by default, 500 at most); `./Memory` the tenant-partitioned in-memory store (`makeStore`, `rows`, `modify`, `repository`); and `./testing` the runner-agnostic contract suite (`repositoryContract`, `ContractFailure`). `Company` now carries `audit: AuditFields` instead of `version`, `Company.create` requires `CurrentActor`, `CompanyRepository` is a `Repository.Port` (adding `getMany`, `find`, `archive` and `restore`, with `Company.find` / `archive` / `restore` accessors), `list` returns only active companies, and `Company.layerMemory` is built on `./Memory`.
